# Data

`event_edges.csv` is generated by `src/generate_events.py`. Each row is one directed event edge in a synthetic endpoint session.

| Field | Description |
|---|---|
| `session_id` | Synthetic session identifier |
| `step` | Event order within the session |
| `source` | Source process or entity |
| `target` | Target process, file, or host |
| `event_type` | Process, file, or network action |
| `bytes_out` | Synthetic outbound byte volume |
| `is_external` | Whether the destination is outside the trusted environment |
| `encoded_command` | Whether the event carries an encoded-command indicator |
| `label` | Benign or attack session label |
